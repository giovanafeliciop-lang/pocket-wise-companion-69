# My Smart Wallet

quero que transforme essa planilha csv anexada em um app profissional de finanças pessoais , completo com o que tem de mais atual nesses tipos de app atualmente. Quero um visual moderno, bonito e profissional, com botões de inserção de novos dados de receitas e despesas. Quero que tenha como adicionar minha fatura do cartão em PDF ou então adicionar imagem ou texto da mesma,  e que as despesas sejam automaticamente separadas por categoria para saber quanto tem sido gasto em cada categoria, independente se foi pago no pix, dinheiro ou cartão. Além disso que te nha como marcar quando cada despesa for paga, para que seja feito um bom controle fianceiro. Quero que os dados sejam gravados no proprio lovable claud.
